# rclone-lab

Aplicativo de uso pessoal. Permite que o programa rclone, num computador da casa do dono, leia e grave arquivos no Google Drive da própria conta do dono, para organizar e processar documentos pessoais.

Não é um serviço público, não tem outros usuários e não é vendido.

Política de privacidade: [privacidade](privacidade.html)
